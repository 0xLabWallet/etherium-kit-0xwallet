## 🎉 Что было сделано

### 1. ⭐ **КРИТИЧНО: Migrated to Etherscan API V2**

#### TransactionSource.kt - Полностью обновлён

**Ключевые изменения:**
- ✅ Добавлен `chainId: Int` в `SourceType.Etherscan`
- ✅ Единый endpoint: `ETHERSCAN_API_V2_BASE_URL = "https://api.etherscan.io"`
- ✅ Поддержка ротации API keys через `List<String>`
- ✅ Метод `apiKey.random()` для автоматического выбора ключа

**Было (v1.2):**
```kotlin
fun ethereumEtherscan(apiKey: String): TransactionSource {
    return etherscan("api", null, apiKey)
}
```

**Стало (v1.3):**
```kotlin
fun ethereumEtherscan(apiKey: List<String>): TransactionSource {
    return TransactionSource(
        "etherscan.io",
        SourceType.Etherscan(
            ETHERSCAN_API_V2_BASE_URL,  // Единый endpoint
            "https://etherscan.io", 
            apiKey.random(),  // Ротация ключей
            1  // chainId для Ethereum
        )
    )
}
```

## 🎯 API Changes

### Breaking Changes

#### 1. ethereumEtherscan() - Теперь принимает List<String>

**Старый способ (v1.2):**
```kotlin
val source = TransactionSource.ethereumEtherscan("YOUR_API_KEY")
```

**Новый способ (v1.3):**
```kotlin
// С одним ключом
val source = TransactionSource.ethereumEtherscan(listOf("YOUR_API_KEY"))

// С несколькими ключами (рекомендуется)
val apiKeys = listOf(
    "ETHERSCAN_KEY_1",
    "ETHERSCAN_KEY_2",
    "ETHERSCAN_KEY_3"
)
val source = TransactionSource.ethereumEtherscan(apiKeys)
// Автоматически выбирает случайный ключ
```

#### 2. bscscan() - Теперь принимает List<String>

**Старый способ (v1.2):**
```kotlin
val source = TransactionSource.bscscan("YOUR_BSC_API_KEY")
```

**Новый способ (v1.3):**
```kotlin
val bscKeys = listOf("BSC_KEY_1", "BSC_KEY_2")
val source = TransactionSource.bscscan(bscKeys)
```

## 📱 Использование в проектах

### Installation

**settings.gradle:**
```gradle
maven { url 'https://jitpack.io' }
```

**app/build.gradle:**
```gradle
dependencies {
    implementation 'com.github.0xLabWallet:etherium-kit-0xwallet:v1.3'
}
```

### Пример использования:

```kotlin
import com.wallet0x.ethereumkit.core.EthereumKit
import com.wallet0x.ethereumkit.models.TransactionSource

// Настройка с ротацией ключей
val apiKeys = listOf(
    "ETHERSCAN_API_KEY_1",
    "ETHERSCAN_API_KEY_2",
    "ETHERSCAN_API_KEY_3"
)
val transactionSource = TransactionSource.ethereumEtherscan(apiKeys)

// Инициализация EthereumKit
val ethereumKit = EthereumKit.getInstance(
    context = applicationContext,
    words = listOf("your", "seed", "phrase", "..."),
    passphrase = "",
    networkType = NetworkType.EthMainNet,
    syncMode = SyncMode.ApiSyncMode(),
    transactionSource = transactionSource,
    walletId = "wallet_id"
)

ethereumKit.start()
```

## 🎯 Преимущества v1.3

### 1. **Улучшенная надёжность**
- API V2 более стабилен
- Единый endpoint для всех сетей
- Меньше точек отказа

### 2. **Защита от rate limiting**
- Автоматическая ротация API keys
- Распределение нагрузки

### 3. **Современная архитектура**
- namespace для лучшей совместимости
- chainId для точной идентификации сети
- Будущие улучшения проще интегрировать

- Меньше DNS запросов (единый endpoint)
- Оптимизированная работа с API
